# ShortBlock
A user-script to get rid of all evidence of Youtube shorts!

My first ever user-script, built for Hack Club's Crescent!

It simply adds a hidden class to most Youtube shorts elements so you can't get distracted!

## Installation

on chrome, chromium or anything chromium based:

1. go to the chrome web store and install either [TamperMonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) or [ViolentMonkey](https://chromewebstore.google.com/detail/violentmonkey/jinjaccalgkegednnccohejagnlnfdag)
2. Go to chrome://extensions and find the extension you just installed
3. Press 'Details' and toggle 'Allow User Scripts'
4. Go to [the GreasyFork listing](https://greasyfork.org/en/scripts/605558-shortblock) and click 'install version 0.01'
5. Go to Youtube and enjoy!
